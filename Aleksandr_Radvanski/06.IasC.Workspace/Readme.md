#6.1.3
Парами создаютс машины, которые должны работать в кластере или в режиме реполикации. \
Остольные машины будут использловатся в единственном экземпляре.

#6.1.4
Данное ограниение требуется для того, что бы каждый студент мог развернуть и контралировать свои уникальыне машины, и не мог взаимодествоваться с машинами 
других студентов.\ Pool обеспечивает разграничение прав студентов на блок машин в соответствии с выданными студенку id. \
В случае же совпадения VMID у студентов - сервер выдаст ошибку.

#6.3.3 \
Terragrant всегда создает свои данные по пути .terragrunt-cache/... . Даже если в корневой папке уже будет создан файл от Terraform и мы принудительно в конфиге укажем его месторасположение, Terragrant принудительно создаст новый, а старый останется не тронутым. \
Для объеденения конфигурации требуется либо копирование файла, либо через import: \
terragrunt import proxmox_virtual_enviroment_pool.student_pool "student-##".

#6.3.4 \
include - указывает наследловаине настроек из root.hcl. \
generate - динамическое создание конфигурационных файлов. \
input - указание персанальных параметров (id) для каждого отдельного студента. 

#6.3.5 \
При размещении параметров pool_id в общем root.hcl - возникли бы противоречия в назначении прав доступа, все машины разварачивались бы в один пул. 

#6.4.2 \
Служба Cloud-ini считывает метаданные переданыне из Terraform при первом запуске системы и перезаписывает ее конфигурацию. \
/etc/cloud/cloud.cfg - позволятет обходить стандартные ограничения образа. (не нашел на машине). \
/etc/ssh/sshd_config.d/**_cloud-init.conf - конфиг файл ssh-сервера. Вносятся изменения в параметры: Permit RootLogin, PasswordAuthentication.

#  HW 07.Ansiblestart

## Homework Assignment 1

Ansible установлен из пакетов Debian 13 ```apt install ansible```. Там не самая свежая версия, но ее полностью хватает

Создан простой сценарий с заглушкой в виде ```hosts: localhost```, потому что ansible требует эту переменную в playbook

Запускалось через команду ```ansible-playbook HW-1/playbook.yml```

## Homework Assignment 2

Создана отдельная папка для описания конечных хостов. Для установки пакетов в целевую систему Debian использована встроенная коллекция ```ansible.builtin.apt```. Также использована комманда ```become: true``` для запроса ввода sudo пароля, так как подключение к целевой системе осуществляется не от root, а для работы пакетного менеджера требуется эскалация привелегий

Для запуска требуется указать через ключ ```-i``` файл инвентаризации хостов и ключ ```-K``` для получения sudo пароля целевой машины

## Homework Assignment 3

Использованы встроенные коллекции ```ansible.builtin.user``` и ```ansible.builtin.group```

Все переменные имеют дефолтные значения

# Homework 05.IasC

## Homework Assignment 1: First configuration and state

* ```tofu init``` - подготавливает директорию, устанавливает необходимые зависимости и т.п.
* ```tofu fmt``` - Приведет файлы к стандартному формату
* ```tofu validate``` - Проверка конфигураций на соответсвие синтаксису 
* ```tofu plan``` - Покажет какие изменение будут внесены
* ```tofu apply``` - Создает или обновляет инфраструктуру

Если инфраструктура находится в заданном состоянии, значит многократное выполнение  ```tofu apply``` не приведет к ее изменению

Если ```tofu state random_password.password``` еще скроет чувствительные данные в выводе, то в файле ```terraform.tfstate``` они будут хранится в открытом тексте и такое нельзя синхронизировать в Git

## Homework Assignment 2: Variables, outputs and locals

```-var``` имеет наибольший приоритет. Если имена перменных совпадают, будет взято значение из ```-var```
```*.tfvar``` имеет приоритет над переменной среды

## Homework Assignment 3: Modules

Модули выгоднее всего использоват когда необходимо повторное исполнение одного и того же действия, но с разными входными данными. Также в модули целесообразно выделять действия, создающие одную общую среду, например, развертывание веб сервера: статические файлы, настройки, сам веб-сервер для использования их как базу для последующих действий

# Helm command history

```bash
helm version --short

kubectl apply --context k8s \
  -f https://raw.githubusercontent.com/rancher/local-path-provisioner/v0.0.36/deploy/local-path-storage.yaml

kubectl apply --context k8s -f namespace.yaml

helm upgrade --install wordpress \
  oci://registry-1.docker.io/bitnamicharts/wordpress \
  --version 32.1.12 \
  --namespace homework-13 \
  --values wordpress-values.yaml \
  --wait --timeout 15m

helm upgrade --install drupal \
  oci://registry-1.docker.io/bitnamicharts/drupal \
  --version 23.0.0 \
  --namespace homework-13 \
  --values drupal-values.yaml \
  --wait --timeout 15m

kubectl apply --context k8s -f istio-routing.yaml
helm list --namespace homework-13
kubectl get pods,pvc,service --namespace homework-13
```

Application and database passwords are generated by the charts and stored only
in Kubernetes Secrets. No password is passed on the command line or committed
to Git.

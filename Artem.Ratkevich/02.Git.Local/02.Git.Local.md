# 02.GIT.Local
---

## Task 1. Initializing a Local Repository


```bash
mkdir git-hometask
cd git-hometask
git init
touch README.MD
git add .
git config --global user.email 'artem.ratkevich.95@mail.ru'
git config --global user.name 'Artem.Ratkevich'
git commit -m"added README.MD"
git status
```

## Task 2. Basic Version Control

```bash
git checkout -b feature-branch
git status
git branch
nano README.MD
git add .
git commit -m "updated README.MD"
git checkout master
git merge feature-branch
```

## Task 3. Exploring Git History

```bash
git log
git log --oneline
git log --pretty=format:"%h - %an, %ar : %s"
git log --pretty=format:"%C(yellow)%h%Creset %Cgreen%ad%Creset %Cblue%an%Creset - %s" --date=short
git log --graph --oneline --decorate
```

## Task 4. Creating and Applying Tags

```bash
git show 3ca948b
git tag "V1.0" 3ca948b
git show 3ca948b
nano README.MD
git add .
git commit -m "update text in README.MD"
git log
git tag "V2.0" 69ffbdba10d14941efdd0b12a7861c61d03a0b73
git log --pretty=format:"%C(yellow)%h%Creset %Cgreen%ad%Creset %Cblue%an%Creset - %s" --date=short
git tag -d "V2.0"
git tag -a v2.0 -m "my version 2.0"
git log
git show
```

## Task 5. Undoing Changes

```bash
git checkout -b bug-fix
nano README.MD
git add .
git commit -m"fixed version in README.MD"
nano README.MD
git add .
git commit -m "fixed another version in README.MD"
git reset --soft HEAD~1
git status
git log --oneline
cat README.MD
git reset --hard HEAD~1
cat README.MD
git log --oneline
git reset --mixed HEAD~1
git status
```

## Task 6. Stashing Changes

```bash
git checkout -b experimental-feature
nano README.MD
git stash
git checkout feature-branch
cat README.MD
git stash apply
git add README.MD
git status
git commit -m 'Applied stash'
cat README.MD
```

## Task 7. Git Aliases and Configuration

```bash
git config --global user.email 'artem.ratkevich.95@mail.ru'
git config --global user.name 'Artem.Ratkevich'
git config --global alias.sync "git commit -m 'Applied stash after resolving merge conflict' pull && git push"
git config --get-regexp alias
git config --global alias.lg "log --oneline --graph --decorate --all"
git lg
```
